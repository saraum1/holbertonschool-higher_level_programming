# JavaScript DOM Manipulation

## Description
A project focused on manipulating the DOM and handling events using JavaScript, following the **semistandard** style.

## Key Objectives
* Selecting HTML elements.
* Modifying styles and content.
* Handling user events.
* Fetching data from external APIs.

## Requirements
* No `var` used.
* Chrome compatible.
* No page reloads.
