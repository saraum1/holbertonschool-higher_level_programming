# Python - Server-Side Rendering

## Description
A comprehensive project on **Server-Side Rendering (SSR)** using Python. It covers dynamic content generation, Flask web development, and data integration from JSON, CSV, and SQLite.

## Project Structure
- **Task 0:** Simple Python string templating and file generation.
- **Task 1:** Basic Flask setup and HTML rendering.
- **Task 2:** Dynamic templates using Jinja2 (Loops & Conditions).
- **Task 3:** Data fetching from JSON and CSV files.
- **Task 4:** Database integration with SQLite.

## Requirements
- Python 3.10+
- Flask
- Pycodestyle compliant
